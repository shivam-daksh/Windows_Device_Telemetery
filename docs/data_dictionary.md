# Data Dictionary

This document defines the schema, units, ranges, nullability, and formatting rules for all CSV telemetry files generated by the **Windows Device Telemetry Monitor**.

---

## 1. File Specification

- **Character Encoding**: UTF-8 (RFC 3629).
- **Delimiter**: Comma (`,`, ASCII 0x2C).
- **Quoting**: Double quotes (`"`, ASCII 0x22). Quoting is applied when a field contains a comma, quote, or newline character. Internal quotes are escaped by doubling (`""`) in accordance with RFC 4180.
- **Line Terminators**: CRLF (`\r\n`) or LF (`\n`).
- **Null Value Representation**: Empty string (e.g., `,,`). **No false zeros** are emitted for unknown or baseline metrics.

---

## 2. System Metrics: `system_metrics.csv`

| Column Name | Data Type | Unit | Nullable? | Valid Range | Description & Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp_utc` | `string` | ISO 8601 | No | `YYYY-MM-DDTHH:MM:SS.mmmZ` | Coordinated Universal Time (UTC) timestamp captured at sample initiation. |
| `elapsed_ms` | `uint64` | Milliseconds | No | $\ge 0$ | Monotonic elapsed time in milliseconds since the start of the monitoring session. |
| `cpu_utilization_percent` | `double` | Percent (%) | **Yes** | `0.00` – `100.00` | System-wide CPU utilization over the previous sampling interval. Empty on sample #1 (baseline) or on counter anomalies. |
| `physical_memory_total_bytes` | `uint64` | Bytes | No | $> 0$ | Total physical RAM installed and accessible to Windows (`ullTotalPhys`). |
| `physical_memory_available_bytes` | `uint64` | Bytes | No | $\ge 0$ | Physical RAM immediately available for allocation without paging (`ullAvailPhys`). |
| `physical_memory_used_percent` | `double` | Percent (%) | **Yes** | `0.00` – `100.00` | Percentage of physical RAM in active use: $(\text{Total} - \text{Avail}) / \text{Total} \times 100$. |
| `virtual_memory_total_bytes` | `uint64` | Bytes | No | $> 0$ | Total user-mode virtual address space size (`ullTotalVirtual`). |
| `virtual_memory_available_bytes` | `uint64` | Bytes | No | $\ge 0$ | Unreserved and uncommitted virtual address space (`ullAvailVirtual`). |
| `memory_load_percent` | `uint32` | Percent (%) | No | `0` – `100` | Windows memory load indicator returned directly by `GlobalMemoryStatusEx` (`dwMemoryLoad`). |
| `ac_line_status` | `string` | Categorical | No | `"Online"`, `"Offline"`, `"Unknown"` | Power supply state: `"Online"` (mains AC connected), `"Offline"` (running on battery), or `"Unknown"`. |
| `battery_flag` | `string` | Bitmask / String | No | e.g. `"Charging\|High"`, `"NoBattery"`, `"Normal"` | Battery state indicators decoded from `SYSTEM_POWER_STATUS::BatteryFlag`. |
| `battery_percent` | `uint32` | Percent (%) | **Yes** | `0` – `100` | Battery charge percentage. **Empty** if battery status is unknown (`255`) or system has no battery. |
| `battery_remaining_seconds` | `uint32` | Seconds | **Yes** | $\ge 0$ | Estimated remaining battery operating time in seconds. **Empty** if connected to AC, unknown, or no battery. |
| `skipped_process_count` | `uint32` | Count | No | $\ge 0$ | Number of active processes skipped during enumeration due to access restrictions (e.g. SYSTEM, PPL, Anti-Cheat). |

## 3. Process Metrics: `process_metrics.csv`

Recorded when `--include-processes true` is enabled. Contains the top $N$ processes ranked by CPU consumption.

| Column Name | Data Type | Unit | Nullable? | Valid Range | Description & Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp_utc` | `string` | ISO 8601 | No | `YYYY-MM-DDTHH:MM:SS.mmmZ` | Coordinated Universal Time (UTC) timestamp corresponding to the sample cycle. |
| `process_id` | `uint32` | PID | No | $> 0$ | Windows Process Identifier (PID). PID 0 (System Idle) is excluded. |
| `process_name` | `string` | Text | No | Filename | Base executable name (e.g., `svchost.exe`, `explorer.exe`). Escaped per RFC 4180 if containing commas or quotes. |
| `process_cpu_percent` | `double` | Percent (%) | **Yes** | `0.00` – `100.00` | Process CPU share of total system capacity normalized across all logical processors. **Empty** on first sample or upon PID reuse. |
| `working_set_bytes` | `uint64` | Bytes | No | $\ge 0$ | Current physical working set size in bytes (`WorkingSetSize` from `PROCESS_MEMORY_COUNTERS`). |
| `page_fault_count` | `uint64` | Count | No | $\ge 0$ | Cumulative page faults (soft + hard) triggered by this process since launch (`PageFaultCount`). |
